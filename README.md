# 🎓 CampusSync

CampusSync is a student-focused platform where users can buy, sell, and discuss academic resources within their campus.

---

## 🚀 Features

* Buy & sell items
* Create and like posts
* Edit and delete posts
* User authentication

---

## 🛠️ Tech Stack

* Frontend: HTML, CSS, Bootstrap, EJS
* Backend: Node.js, Express.js
* Database: MongoDB
* Authentication: JWT
